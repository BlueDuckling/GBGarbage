# GameBoy Emulator

A Game Boy emulator written in C++.

## About

This project aims to emulate the original Nintendo Game Boy hardware. It is a personal project made for fun and to learn more about low-level programming, computer architecture and emulation. Right now it's only capable of emulating the Blargg test ROMs for CPU instructions. The PPU will be implemented next.

## Features

- CPU implementation
- CPU registers and instructions

## Building

The project can be compiled using Visual Studio or a compatible C++ compiler.

## Running

Since it is an early WIP, the rom path must be hardcoded in the main.cpp file.

## Tests

The roms directory is intended for testing CPU instructions using the Blargg test ROMs.
